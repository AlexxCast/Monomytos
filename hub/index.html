Impostazioni

Per vedere i dati non serve niente. Per inviare, aggiornare e scrivere all'AI serve una chiave GitHub personale. Resta solo in questo browser, non viene mai salvata nel sito.

Come creare la chiave (2 minuti)
  1. Apri github.com → Settings → Fine-grained tokens → Generate new token.
  2. Nome: Centro social. Scadenza: 1 anno.
  3. Repository access: Only select repositories → solo Monomytos.
  4. Permissions → Repository: Actions Read and write, Contents Read and write, Issues Read and write.
  5. Generate token, copialo e incollalo qui sopra. Fallo su ogni telefono o PC da cui usi il Centro.
